# Lampa Apple TV theme

A [Lampa](https://github.com/lampa-app) plugin that restyles the TV interface toward tvOS: lifted posters, white‑pill focus, frosted floating panels, a full‑bleed title page and clean shelves. It's CSS plus one small text tweak; remove the plugin to get stock Lampa back.

## Install

In Lampa, open **Настройки → Расширения → Добавить плагин** and enter:

```
https://andrewkuktenko.github.io/lampa-appletv-theme/appletv.js
```

Then restart Lampa.

## Notes

- Tuned for 1080p UI on Android TV / Google TV. It avoids per‑frame blur on hidden panels, so it stays smooth on weak TV GPUs.
- Uses [Inter](https://rsms.me/inter/) from Google Fonts.
- Personal, non‑commercial project. Not affiliated with Apple or Lampa.
